## App Review (İnceleme) bilgileri
- **Giriş bilgisi:** Gerekmez (hesap yok).
- **İnceleme notu (İngilizce yazın):**
```
Secdem is a native Capacitor app with on-device features, not a website wrapper:
- Local notifications at prayer times (scheduled on-device, custom sound)
- Core Location for prayer times, Qibla direction and nearby mosques
- Core Motion / heading for the Qibla compass
- Camera / photo library to read names from a gravestone photo (OCR runs on-device)
- Grave records are stored only on the device
Internet is used for prayer time data, Quran audio and the mosque map. No account is required.
Ads: Google AdMob banner on inner screens only (none on the home screen) and an occasional interstitial; ATT prompt is shown before personalized ads.
```
